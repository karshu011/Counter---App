# 🔢 Counter App

A simple and interactive Counter application developed using HTML, CSS, and JavaScript. This application allows users to increase, decrease, and reset the counter value.

## 🚀 Features

- ➕ Increase counter value
- ➖ Decrease counter value
- 🔄 Reset counter to zero
- 🔢 Display current count
- ⚡ Instant value updates
- 🎨 Simple and attractive user interface
- 📱 Responsive design
- 🖱️ Easy-to-use buttons

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

Counter-App/

## ⚙️ How to Run

1. Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Open the project folder.

3. Open `index.html` in your browser.

4. Click the Increase or Decrease button to change the count.

5. Click Reset to return the counter to zero.
